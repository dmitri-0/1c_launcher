# Менеджер заметок в лаунчере 1С — концепция (ветка `feat/notes-manager`)

Референс: FlashNote Portable 4.8 (`c:\ROOT\flashnote_portable_4.8\`) — изучен:
дерево заметок на SQLite (`notes2.db`, таблица `notes3`), конфиг INI, портативный exe,
547 заметок, глубина 2+, «папка» = узел с детьми, тело — преимущественно plain text.

## 1. Что берём от FlashNote, чего не берём

| Берём | Не берём |
|---|---|
| Модель «дерево заметок на SQLite» (смежный список: id/pid/name/note/…) | Запуск чужого exe / парсинг его формата как основного хранилища |
| Портативность (данные рядом с exe, настраиваемый путь) | Его INI-конфиг — у нас уже свой `launcher.toml` |
| Поиск, корзина, быстрая вставка из буфера, бэкапы | Полное дублирование всех 40+ опций |

Главное отличие: заметки живут **внутри** лаунчера и могут быть **привязаны к базам 1С** —
это то, чего у FlashNote нет и что даёт реальную интеграционную ценность.

## 2. Ценность интеграции

1. **Одно окно**: рядом с базами 1С лежат заметки про эти базы (что меняли в конфигураторе,
   когда публиковали, как подключаться, пароли/доступы).
2. **Привязка к базе 1С** (`db_ref`): заметка видна прямо у узла базы (бейдж «🔖 N» и/или
   подузел «Заметки» при разворачивании).
3. **Глобальный хоткей «быстрая заметка»** из любого места (аналог перехвата `nm ` в FlashNote):
   Alt+N → маленькое окно с текстом из буфера обмена → сохранить.
4. Всё настраивается в уже внешнем `launcher.toml` — без пересборки.

## 3. Хранение

SQLite (stdlib `sqlite3`), файл `notes.db` рядом с exe (портативно, как FlashNote);
путь переопределяется в `launcher.toml`:

```toml
[notes]
path = ''              # пусто = notes.db рядом с exe
hotkey_quick_note = 'Alt+N'
editor_font = 'JetBrains Mono'
backup_enabled = true
backup_period_days = 7
```

Схема (адаптация `notes3`, плюс привязка к базе):

```sql
CREATE TABLE notes(
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  pid INTEGER NOT NULL DEFAULT 0,      -- родитель; 0 = корень; папка = узел с детьми
  name TEXT NOT NULL DEFAULT '',       -- заголовок
  note TEXT NOT NULL DEFAULT '',       -- тело: HTML (QTextEdit::toHtml)
  pos INTEGER NOT NULL DEFAULT 0,      -- порядок внутри папки
  db_ref TEXT NOT NULL DEFAULT '',     -- привязка к базе 1С (connect-строка или имя базы)
  created TEXT NOT NULL,
  modified TEXT NOT NULL,
  trash INTEGER NOT NULL DEFAULT 0
);
CREATE TABLE meta(key TEXT PRIMARY KEY, value TEXT);  -- schema_version и пр.
```

- **Тело — HTML** через `QTextEdit` (форматирование, списки, ссылки, картинки);
  поиск по тексту — с удалением HTML-тегов.
- **Миграции**: `meta.schema_version`, стартовая миграция создаёт таблицы.

## 4. UI: как встроено в дерево лаунчера

- Новый корневой узел **«📝 Заметки»** (в дереве, рядом с «Открытые базы»/«Основное»).
- Узлы: папки `📁` и заметки `📄`; у баз 1С — бейдж `🔖 N`, если есть привязанные заметки.
- **Взаимодействие:**
  - `Enter`/двойной клик по заметке → **редактор-диалог** (заголовок + `QTextEdit` +
    панель: B/I/U, списки, ссылки) — паттерн `DatabaseSettingsDialog` проекта;
  - контекстное меню: создать заметку/папку, переименовать, удалить (в корзину);
  - `F2` — переименовать; `Del` — в корзину (контекстно: только для узлов «Заметки»,
    в других разделах `Del` работает как сейчас);
  - поиск: `Ctrl+F` фильтрует дерево заметок по имени и тексту (аналог `SearchFilterTree`);
  - корзина: узел «🗑 Корзина» внутри «Заметки», восстановление / очистка;
  - **автосохранение** при редактировании (debounce ~0.5 с) + при выходе.
- Фаза 2+: **drag&drop** для структуры (встроено в `QTreeView`), разворачивание базы →
  подраздел «Заметки».

## 5. Горячие клавиши

| Клавиша | Действие | Где настраивается |
|---|---|---|
| `Ctrl+N` (фокус в «Заметках») | новая заметка | `[notes]` launcher.toml |
| `Alt+N` (**глобальная**) | быстрая заметка из буфера обмена | `[notes] hotkey_quick_note` |
| `F2` / `Del` | переименовать / в корзину | контекстное меню |

`GlobalHotkeyManager` расширяется на несколько ID (сейчас один Alt+D) — общий механизм уже есть.

## 6. Связь с базами 1С

- В редакторе — кнопка **«Привязать к базе»**: подставляется выбранная в дереве база
  (имя/connect-строка в `db_ref`).
- В дереве баз: бейдж `🔖 N` у узла базы; при разворачивании — подузел «Заметки» (Фаза 2).
- Опционально (Фаза 3): при открытии базы (`Enter`) показывать напоминание, если у базы
  есть заметка с флагом «показывать при запуске».

## 7. Структура кода (паттерн проекта — миксины)

```
src/notes/
  __init__.py
  notes_manager.py      # SQLite: CRUD, дерево, поиск, корзина, миграции, бэкап
  notes_dialog.py       # редактор заметки (QDialog)
  quick_note_dialog.py  # быстрая заметка из буфера (глобальный хоткей)
  notes_tree_builder.py # построение узла «📝 Заметки» в дереве
src/gui/mixins/notes_mixin.py  # подключение: хоткеи, контекстное меню, refresh
```

Подключение в `TreeWindow` — как остальные миксины (`SnapshotsUpdateMixin` и т.п.);
построение дерева — через `QStandardItemModel` (уже используется).

## 8. Этапы

- **Фаза 1 (MVP):** `notes_manager` (SQLite) + узел «📝 Заметки» + редактор-диалог +
  создание/переименование/удаление (корзина) + поиск по имени.
- **Фаза 2:** глобальный хоткей «быстрая заметка», drag&drop, привязка к базе (`db_ref` + бейдж).
- **Фаза 3:** напоминания при открытии базы, экспорт (txt/html), автобэкап, шаблоны вставки
  (дата/время — аналог `%ExTime%`).

## 10. Решения и первый вариант (v1) — реализовано в ветке `feat/notes-manager`

Принятые решения:
- **Тело заметки — plain text.** Форматирование — по `F4`: движок определяет формат и
  рендерит **preview** (пока понимает только **Markdown**), если формат не распознан —
  показывает как plain text. В будущем список форматов расширится.
- **Привязка к базе (`db_ref`) — отложена** (не понятно пока, как использовать).
- **Отдельный модуль** `src/notes/` + отдельный корневой узел **«📝 Заметки»** в дереве.
- **Импорт из FlashNote — не нужен.**
- **Хранение — SQLite** (`notes.db` рядом с exe/модулем; путь — `[notes] path` в `launcher.toml`).

Что реализовано в v1:
- `NotesManager` (SQLite): дерево смежным списком (`pid`), папки (`type=1`), заметки (`type=0`),
  CRUD, корзина (`trash`), полное удаление поддерева; `guess_note_format()` — определение
  формата (md по расширению имени `.md`/`.markdown` или по маркерам, иначе plain).
- `NotesDialog`: заголовок + текст; `F4` — переключение preview/редактирование; в preview
  Markdown рендерится (`QTextEdit::setMarkdown`), нераспознанный формат — plain text.
- `NotesTreeBuilder`: узел «📝 Заметки» в дереве (папки выше заметок, сортировка pos/name).
- `NotesMixin` + `ShortcutsMixin`: `Enter` — открыть заметку/раскрыть папку, `Del` — в корзину
  (только для узлов заметок), `Ctrl+N` — новая заметка, `F2` — переименовать,
  контекстное меню, двойной клик.
- Конфиг: `[notes] path` в `launcher.toml` (`NOTES_PATH` в `config.py`).
- Тесты: `tests/test_notes.py` (формат, CRUD, дерево, корзина, purge, интеграция).

Что отложено на следующие итерации: быстрая заметка по глобальному хоткею (Alt+N), drag&drop,
поиск по тексту, привязка к базам, экспорт, автобэкап, шаблоны.
